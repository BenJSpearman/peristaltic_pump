# Peristaltic Pump

----- OVERVIEW -----
This is a heavily modified version of Drmn4ea's Planetary peristaltic pump (customizable) on Thingiverse (https://www.thingiverse.com/thing:454702).

The goal of this is to create a mounted version which can be attached to a Nema 17 stepper motor, with customizable options for mounting. This will also allow for customization of the pump itself, like it's predecessor. I've updated a number of things from the original code, fixed some bugs, cleaned up formatting, and labelled things for better legibility. Hopefully, this will become a one-stop-shop for people wanting to create custom peristaltic pumps with varying tube sizes, tube types, pump sizes, etc.

----- TESTING -----
There is a .json file with the .scad files which will save out the parameters set for each test. These 'presets' are numbered as v#, and will be associated with the .stl and .gcode files of the same v#. Unfortunately, v2-7 were not saved. However, many code changes have been made since then, so the parameters no longer apply properly anyway.


----- RELEASE -----
This should hopefully be released at some point on Thingiverse, where it's online customizer will be able to be used by people to create custom variations simply through the web, without needing to download any code. Due to this, this repository will most likely be kept private for my own testing ground, as the code will be available for download on Thingiverse.
